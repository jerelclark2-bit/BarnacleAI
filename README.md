# BarnacleAI (older source copy)

This repository has an earlier copy of the BarnacleAI Python project under `BarnacleAI/`.

**The current project lives in [Barnacle-A.I](https://github.com/jerelclark2-bit/Barnacle-A.I).** That's where the actively updated code, trained browser inference, automated tests, and website are kept.

**[Try the browser demo](https://jerelclark2-bit.github.io/Barnacle-A.I/)**

If you're looking at the source here, start with [the original README](BarnacleAI/README.md). For current results and setup instructions, use the active repository instead.

This is a prototype using incomplete annotations, not a validated biological counting tool.
